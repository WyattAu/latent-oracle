# Provenance & Clean-Room Protocol

This repository is developed under a strict clean-room protocol. Every line of
code is either original or derived from a permissively licensed source listed
below. No GPL source code (Stockfish, Berserk, Seer, Ethereal, RubiChess, or
any other engine) has been read, referenced, or copied by any contributor.

## Why

latent-oracle is Apache-2.0. The GPL engine ecosystem is legally off-limits for
code reuse; data is not. Stockfish may be *executed* to generate training
labels (evaluations, PV moves) because labels are facts, not copyrighted
expression. This distinction is load-bearing for the whole project and is the
reason this file exists.

## Protocol

1. Contributors do not read GPL-licensed engine source trees.
2. All chess logic is written from first principles and validated against
   public-domain reference data (Chess Programming Wiki perft counts).
3. Every external influence is recorded in the table below before its effect
   lands in `src/`.
4. Third-party linked code must be Apache/MIT/BSD. Current:
   Fathom (MIT, vendored in third_party/fathom).

## Data provenance (M1+)

* Training positions: Lichess open game database (CC0).
* Labels: generated by executing an unmodified Stockfish binary. Labels are
  data; no Stockfish source is involved at any stage of training or inference.
